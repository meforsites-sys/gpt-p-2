# English 6th Prep 2027 — Android project

مشروع أندرويد أولي يعمل دون إنترنت، ويضم مكتبة نصية قابلة للبحث مستخرجة من ملفات المنهج التي زوّد بها المستخدم.

## بناء APK تلقائياً عبر GitHub Actions

هذا المستودع يحتوي على الملف:

`.github/workflows/build-apk.yml`

ويشغّل الأمر التالي تلقائياً عند `push` أو `pull_request` إلى `main` أو `master`، كما يمكن تشغيله يدوياً من تبويب Actions:

```bash
gradle --no-daemon :app:assembleDebug
```

### خطوات الاستخدام

1. فك ضغط ملف ZIP.
2. أنشئ مستودعاً جديداً على GitHub.
3. ارفع **محتويات المجلد** إلى جذر المستودع (يجب أن يظهر مجلد `.github` في الجذر).
4. افتح تبويب **Actions** في GitHub.
5. اختر **Build Android APK** ثم **Run workflow** إذا لم يبدأ البناء تلقائياً بعد الرفع.
6. بعد نجاح المهمة، افتح تشغيل الـ workflow وانزل إلى **Artifacts**.
7. نزّل `English6thPrep2027-debug-apk.zip`، ثم فك ضغطه لتحصل على `app-debug.apk`.
8. انقل APK إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## البناء محلياً

يتطلب Android Studio / Android SDK وJava 17 وGradle 8.9:

```bash
gradle :app:assembleDebug
```

الناتج:

`app/build/outputs/apk/debug/app-debug.apk`

## ما يحتويه الإصدار الحالي

- واجهة عربية مبسطة مع أقسام الوحدات والقواعد والأدب والبحث.
- بحث محلي دون إنترنت داخل النصوص المستخرجة من: ملزمة الوحدات 1–4، ملزمة الوحدات 5–8، ملف الأدب، وكتاب النشاط.
- ملف خريطة الامتحان الممسوح ضوئياً موجود في `docs/exam_map_scanned.pdf` للرجوع اليدوي.

## حدود يجب معرفتها

- هذا **إصدار أولي قابل للبناء** وليس منصة تعليمية مكتملة بعد؛ لا يحتوي بعد على بنك أسئلة تفاعلي كامل أو تصحيح امتحانات أو حسابات أستاذ/طالب أو مزامنة سحابية.
- ملف خريطة الدرجات ممسوح ضوئياً ولم نضع توزيع درجات غير متحقق منه داخل التطبيق.
- بعض تمارين كتاب النشاط تحيل إلى كتاب الطالب، وهو غير متوفر ضمن الملفات التي تم تضمينها؛ لذلك لا نخترع النصوص أو الإجابات الناقصة.
- البحث نصّي ويعرض مقتطفات، وليس عارض PDF.
- الناتج من GitHub هو Debug APK للتجربة والتثبيت اليدوي، وليس إصداراً منشوراً على Google Play.

## تحديث المادة التعليمية – المرحلة الأولى

أضيف في هذه النسخة فهرس دروس تفاعلي للوحدات الثماني: افتح الوحدة ثم اختر الدرس لعرض مقتطفات مرتبطة بعنوانه من النصوص المستخرجة من الملفات التعليمية. كما أصبح البحث الشامل متاحاً من داخل التطبيق، وأضيفت روابط بحث لموضوعات القواعد والأدب.

**حدود التغطية الحالية:** فهرس الوحدتين الرابعة والثامنة يعرض أربعة دروس فقط لكل منهما، وفق العناوين التي أمكن تحديدها في الملفات المرفقة. بعض أنشطة كتاب النشاط تحيل إلى صفحات من كتاب الطالب غير المرفق؛ لذلك لا تُنشأ إجابات بديلة من عندنا. هذه مرحلة إدخال وفهرسة للمادة، وليست بعدُ بنك أسئلة تفاعلياً أو شرحاً كاملاً للقواعد.

## تنظيم المفردات والمصادر
- أضيف قسم **الكلمات والجداول** ويعرض مفردات الوحدات الثماني في جداول إنجليزية/عربية قابلة للبحث والتصفية.
- المفردات ومعانيها منقولة من ملزمتي الوحدات 1–4 و5–8 وكتاب النشاط المرفق، مع ذكر مصدر كل مجموعة داخل التطبيق.
- لم تُنشأ شروحات قواعد أو معانٍ بديلة من خارج الملفات. عند غياب معنى صريح في المصدر، لا يُضاف معنى تخميني.
- عند تحديث المادة، يجب الحفاظ على عنوان المصدر ورقم الدرس/الصفحة قدر الإمكان، ومراجعة النص المستخرج مع صفحة PDF الأصلية قبل اعتماده.
