# Ali moez – تطبيق تعلم اللغة الإنجليزية

## هوية التطبيق
- الاسم المعتمد داخل التطبيق: **Ali moez**.
- الإصدار المصدري: **1.7.0+7**.
- تطبيق Flutter تعليمي مستقل، مع الاحتفاظ ببنية المشروع السابقة وتطويرها تدريجياً.

## المواد المرفقة
- كتاب/ملزمة الوحدات 1–4 بصيغة PDF.
- كتاب/ملزمة الوحدات 5–8 بصيغة PDF.
- فهرس أولي لمقاطع كتاب النشاط، مع البحث والتصفية حسب الوحدة.

## ضوابط المحتوى
- لا تُضاف أسئلة أو أمثلة من إنشاء التطبيق إلى كتاب النشاط.
- المقاطع المستخرجة آلياً تظل موسومة بأنها تحتاج إلى تدقيق بصري قبل اعتمادها.
- لا يُفعّل التصحيح الآلي إلا بعد التحقق من السؤال ومفتاح إجابته في المصدر.
- أزيل مدخل بنك الأسئلة التجريبي القديم من الواجهة، وأصبح الوصول للتمارين من كتاب النشاط.

## حالة البناء
هذا **مصدر Flutter** وليس APK جاهزاً. لم يُنفذ بناء APK أو اختبار على هاتف في بيئة التحرير الحالية لعدم توفر Flutter SDK. يحتوي المشروع على سير عمل GitHub Actions الموروث لبناء APK عند رفعه إلى مستودع GitHub.

## الإصدار 1.4
- اعتماد الاسم الجديد **Ali moez** في عنوان التطبيق والهوية الظاهرة.
- تحديث رقم الإصدار إلى 1.4.0+4.
- إزالة الوصول إلى بنك الأسئلة التجريبي غير المعتمد من الصفحة الرئيسية، وإزالة شاشة الاختبار القديمة من مصدر التطبيق.
- التأكد من أن ملف PDF المرفق في هذه المحادثة مطابق تماماً لملف الوحدات 1–4 الموجود في المشروع (تطابق SHA-256).
- لم يكتمل بعد التدقيق البصري لكل تمارين الوحدات، ولم تُضف مفاتيح إجابة غير موثقة.

## رفع المشروع إلى GitHub
- ارفع محتويات هذا المجلد مباشرة إلى جذر المستودع (بحيث يظهر `pubspec.yaml` في الصفحة الرئيسية للمستودع).
- يتضمن المشروع سير عمل GitHub Actions في `.github/workflows/build-apk.yml`، ويعمل عند الدفع إلى فرع `main` أو تشغيله يدوياً من تبويب Actions.
